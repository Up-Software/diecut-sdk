# Security policy

## Supported versions

Only the latest minor release of `@up-software/diecut-sdk` receives security fixes. While the
package is below 1.0.0, a fix ships as a new minor or patch release; upgrade to it rather than
waiting for a backport.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a vulnerability.

Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/Up-Software/diecut-sdk/security/advisories/new)
(the **Security** tab, then **Report a vulnerability**).

Include, when you can:

- the affected version,
- a description of the issue and its impact,
- steps or a minimal script to reproduce it.

Never include a real API key in a report. Use a placeholder or a revoked key.

## What to expect

- An acknowledgement within 5 business days.
- An assessment and, if the report is confirmed, a plan for the fix.
- A fix released as a new version, followed by a published GitHub security advisory that credits
  you, unless you prefer to stay anonymous.

## Scope

This policy covers the code in this repository and the package published to npm. Vulnerabilities
in the diecuttemplates.com APIs themselves should be reported to diecuttemplates.com.
